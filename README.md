# Radiicall Music 1.1

Player MP3 Android com reprodução em segundo plano.

## Novidades da versão 1.1
- Novo nome: Radiicall Music
- Interface azul escuro / azul vibrante
- Controle de graves
- Controle de agudos
- Controle de volume
- Menu de três pontos por música
- Remover da biblioteca
- Tentar excluir o arquivo MP3 do aparelho (quando o provedor de arquivos do Android permitir)
- Reprodução em segundo plano e controles do sistema

## Gerar APK no GitHub
1. Envie o conteúdo deste projeto para o repositório.
2. Vá em Actions > Gerar APK Radiicall Music.
3. Clique em Run workflow.
4. Ao finalizar com sucesso, baixe o artifact Radiicall-Music-APK.
5. Dentro dele estará Radiicall-Music.apk.
